# Carga ⚡

> App de sobrecarga progresiva, seguimiento de entrenamientos y nutrición inteligente.

## Stack Tecnológico

- **Framework**: [React Native](https://reactnative.dev/) con [Expo](https://expo.dev/) (SDK 52) & Expo Router
- **Backend & Base de Datos**: [Supabase](https://supabase.com/) (PostgreSQL, Row Level Security, Auth, Edge Functions)
- **Diseño**: Dark Mode industrial enfocado en rendimiento y ergonomía en el gimnasio
- **Plataformas**: iOS, Android y Web

## Inicio Rápido

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Configurar variables de entorno:
   Copiar `.env.example` a `.env.local` y rellenar con tus credenciales de Supabase.

3. Iniciar el servidor de desarrollo:
   ```bash
   npx expo start
   ```
